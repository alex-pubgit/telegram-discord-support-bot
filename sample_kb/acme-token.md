# ACME token

## Which network is the ACME token on?

The ACME token exists on BNB Smart Chain only. A token called ACME on Ethereum, Polygon or any other network is not the official token.

## Where can I find the ACME contract address?

The contract address is deliberately not written in this chat or in these documents. The official ACME contract address is published only on the official website. Do not trust a contract address that someone posts in a chat or sends you in a direct message (DM).
